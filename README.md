🎓 Campus Connect

Campus Connect is a Flask-based web application designed for college event management. It allows students to register for both technical and non-technical events while securely storing participant details in a database. The system includes a user-friendly frontend, flask database integration, registration, and management.


 🚀 Features
* User Registration:** Seamless sign-up for students to register for various college events.
* Event Management:** Helps organize and track technical and non-technical event schedules.
* Secure Database Integration:** Utilizes a backend database to securely store and handle all participant records.
* Responsive Frontend:** Clean, modern user interface designed using Bootstrap for smooth navigation.


 🛠️ Tech Stack
* Backend: Python, Flask
* Frontend: HTML5, CSS3, Bootstrap
* Database: MySQL
